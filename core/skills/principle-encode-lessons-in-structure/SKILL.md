# Encode Lessons in Structure

교훈에 판단이 필요해서 구조로 옮길 수 없다면, 지시를 더 눈에 띄게 하고 실패 양상의 예시를 추가한다.

**따름 정리:** 해결이 구조적이라면 구조적 해결만 쓴다. 지시는 증상이다.
